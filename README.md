# Ứng Dụng Ôn Thi Viết Lại Câu Tiếng Anh 8 - Giữa Học Kỳ 1 (Câu 41 - 80)

Ứng dụng web kiểm tra trực tuyến chuyên đề **Viết lại câu giữ nguyên nghĩa (Sentence Transformation)** dành cho học sinh Tiếng Anh Lớp 8 - Ôn thi Giữa Kỳ 1.

Ứng dụng được xây dựng hoàn toàn bằng **HTML5, CSS3 và Vanilla JavaScript**, không phụ thuộc thư viện nặng hay máy chủ backend, **sẵn sàng chạy mượt mà trên GitHub Pages**, máy tính để bàn, máy tính bảng và điện thoại di động.

---

## 🌟 Tính Năng Nổi Bật

1. ⏱️ **Đồng hồ đếm ngược 20 phút chuẩn phòng thi**:
   - Hiển thị thời gian trực quan dạng sticky bar (luôn nhìn thấy khi cuộn trang).
   - Đổi màu cảnh báo ở 5 phút và 1 phút cuối kèm âm thanh thông báo.
   - **Tự động nộp bài và khóa bài thi** khi hết 20 phút (00:00).

2. 🤖 **Thuật toán chấm điểm thông minh**:
   - Học sinh có thể nhập **cả câu hoàn chỉnh** hoặc **chỉ phần còn lại sau từ gợi ý**.
   - Chuẩn hóa thông minh: không phân biệt hoa thường, tự động xử lý dấu câu, khoảng trắng thừa, chấp nhận các dạng viết tắt phổ biến (`didn't` = `did not`, `can't` = `cannot`, `I'd` = `I would`,...).
   - Chấp nhận nhiều cách diễn đạt tương đương (ví dụ: `in order to` / `so as to`, `so that she can pass` / `so that she will pass`,...).

3. 📖 **Kiểm tra đáp án & Giải thích chi tiết từng câu sau khi nộp**:
   - Chấm điểm trên thang điểm 10 và tỷ lệ số câu đúng/40.
   - Hiển thị đối chiếu rõ ràng: *Bài làm của bạn* vs *Đáp án chuẩn*.
   - Khối bài giảng giải thích chi tiết:
     - 📌 **Cấu trúc ngữ pháp trọng tâm (Formula)**
     - 💡 **Phân tích từng bước biến đổi câu**
     - 📖 **Dịch nghĩa song ngữ Anh - Việt**
     - ⚠️ **Lưu ý bẫy ngữ pháp thường gặp**

4. 🧭 **Tiện ích hỗ trợ học tập**:
   - **Bảng số câu hỏi (Question Palette)**: Bấm vào số câu 41 - 80 để cuộn nhanh đến câu đó; đổi màu trực quan (Chưa làm / Đã làm / Đúng / Sai).
   - **Bộ lọc kết quả**: Xem *Tất cả 40 câu*, *Chỉ xem câu làm đúng*, hoặc *Chỉ xem câu làm sai / chưa làm*.
   - **Tự động lưu tiến trình (Auto-save)**: Lưu vào `localStorage`, không lo mất bài khi lỡ tải lại trang.
   - **Chế độ Giao diện**: Chuyển đổi linh hoạt Sáng (Light) / Tối (Dark).
   - **In đề & Xuất PDF**: Hỗ trợ định dạng in ấn sạch đẹp để phát đề kiểm tra trên lớp hoặc lưu lại ôn tập.

## 🚀 Hướng Dẫn Chạy Trên GitHub (GitHub Pages)

Để đưa ứng dụng này lên mạng Internet miễn phí và chạy vĩnh viễn trên GitHub Pages, bạn chỉ cần thực hiện 3 bước đơn giản:

### Bước 1: Đẩy mã nguồn lên GitHub Repo
Mở Terminal / PowerShell tại thư mục này và chạy các lệnh:
```bash
git init
git add .
git commit -m "Khoi tao ung dung thi Tieng Anh 8 cau 41-80"
git branch -M main
git remote add origin https://github.com/<USERNAME>/<TEN-REPO>.git
git push -u origin main
```
*(Thay `<USERNAME>` bằng tài khoản GitHub của bạn và `<TEN-REPO>` bằng tên repository bạn vừa tạo)*.

### Bước 2: Kích hoạt GitHub Pages
1. Truy cập vào trang Repository trên GitHub: `https://github.com/<USERNAME>/<TEN-REPO>`.
2. Bấm vào tab **Settings** (Cài đặt) ở thanh menu trên cùng.
3. Ở menu bên trái, chọn mục **Pages**.
4. Tại phần **Build and deployment** -> **Branch**:
   - Chọn nhánh: **`main`**
   - Thư mục: **`/ (root)`**
   - Bấm **Save** (Lưu).

### Bước 3: Truy cập website
Sau khoảng 1 - 2 phút, GitHub sẽ hoàn tất triển khai. Bạn có thể truy cập website tại đường dẫn:
```
https://<USERNAME>.github.io/<TEN-REPO>/
```
Học sinh có thể truy cập bằng bất kỳ thiết bị nào (máy tính, điện thoại, máy tính bảng) qua đường link này mà không cần cài đặt bất kỳ phần mềm nào.
